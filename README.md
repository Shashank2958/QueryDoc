# QueryDoc

QueryDoc is an AI-powered document question-answering application that allows users to interact with their documents using natural language. Users can provide a document, ask questions related to its content, and get relevant answers based on the information available in the document.

The project explores **LLMs, document processing, embeddings, vector search, and Retrieval-Augmented Generation (RAG)** to create a conversational interface for querying documents efficiently.

### Key Features

* 📄 Document-based question answering
* 🔍 Semantic search for relevant document content
* 🤖 AI-generated answers using retrieved context
* 🧠 Retrieval-Augmented Generation (RAG)
* 💬 Natural-language interaction with documents
* ⚡ Fast and context-aware responses

### Technologies

* Python
* LLMs
* RAG
* Embeddings
* Vector Database
* Document Processing

QueryDoc is built as a learning and practical project to understand how modern AI applications combine **LLMs with external knowledge sources** to provide context-aware responses.
